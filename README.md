# 🍕 Saizelysees (サイゼリーゼ)
### 〜 温もりとコスパの奇跡！サイゼ風イタリアンレストラン経営ゲーム 〜

サイゼリヤをリスペクトした、温かみのあるピクセルアート（ドット絵）＆アイソメトリック視点のイタリアンレストラン経営シミュレーションゲームです。
添付のグランドメニュー表『楽しい食卓 La Buona Tavola!』の世界観や配色を取り入れ、壁掛けのドット絵ポスターや名物料理、設備、スタッフの成長を体験できます。

---

## 🎮 ゲームの特徴

### 1. 世界観 & ピクセルアート
- **アイソメトリック視点**: 温かみのある斜め見下ろし視点のフロア。
- **サイゼカラー**: イタリアンレッド、サイゼグリーン、クリームホワイト、テラコッタタイルを基調とした配色。
- **原点の壁画ポスター**: グランドメニュー表『楽しい食卓 La Buona Tavola!』を精緻なピクセルアート（ドット絵）に変換。店内の北壁に飾られ、タップすることで原画と比較しながら拡大鑑賞可能（客の満足度+15%効果）。
- **リアルタイムアニメーション**:
  - パスタ茹で麺器から立ち上るもくもくの湯気パーティクル♨️
  - 2段コンベアオーブンから漏れる赤い熱気と湯気🔥
  - 食事中の熱々料理から立ち上る湯気
  - 店員（緑エプロン）が注文を取り、熱々の料理をトレイに乗せて配膳
  - キッチンシェフ（赤バンダナ）がフライパンやオーブンでフル稼働
  - お客さんが座り、注文ベル🛎️を鳴らし、もぐもぐ食べて「Buono!❤️」と喜ぶ
  - 会計時にレジで「チャリン！💰」と売上コインが跳ね上がる演出

### 2. 本格レシピ＆料理作り (`recipe.md` 完全準拠)
全カテゴリ・30品以上の充実メニューを網羅！
- **パスタ枠**: ミートパスタ、パルマ風パスタ、ペペロンチーノ、カルボナーラ、たらこのパスタ、イカスミのパスタ、きのこのクリームパスタ、ペンネアラビアータ、ほうれん草のソテー
- **サラダ・スープ枠**: 小エビのサラダ、チキンのサラダ、わかめのサラダ、小エビのカクテル、蒸し鶏の香味ソース、コーンスープ、たまねぎのズッパ
- **ドリア＆グラタン枠**: ミラノ風ドリア、焼きチーズミラノドリア、たらこのドリア、たらこのグラタン
- **ピザ枠**: バッファローピザ、野菜ときのこのピザ、ソーセージピザ、コーンピザ
- **前菜枠**: ポップコーンシュリンプ、ポテトのグリル、チョリソー、辛味チキン
- **焼きたてパン枠**: フォッカチオ、シナモンフォッカチオ、ガーリックフォッカチオ、たらこのフォッカチオ、チーズフォッカチオ
- **肉料理枠**: ハンバーグ、イタリアンハンバーグ、ディアボラ風ハンバーグ、ミックスグリル、若鶏のディアボラ風、柔らかチキンのチーズ焼き、付け合わせ目玉焼き
- **ワイン枠**: 白マグナム (1500ml)

#### 🍳 本格調理ミニゲーム
調理中のテーブルをタップ、またはレシピ図鑑から「手動クッキング」を選択すると、`recipe.md`の手順通りに材料を投入・炒める・オーブンの焼き加減ゲージを止めるインタラクティブなミニゲームが起動！パーフェクト調理でボーナス売上＆EXP獲得！

### 3. 経営システム (ダミーなし、全状態変化)
- **厨房設備強化**: 茹で麺器（パスタ短縮）、オーブン（焼き時間短縮）、サラダ台、ドリンクバー（客単価+50円）、高速レジ
- **スタッフ雇用＆育成**: フロアスタッフ（給仕係）やキッチンシェフの雇用、トレーニング昇給
- **店内装飾**: 原点の額縁ポスター、イタリア国旗、アンティーク照明、オリーブの鉢植え、ワインウッドラック
- **店舗拡張**: 街角の2席からスタートし、4席・6席・8席の巨大フラッグシップ本店へと拡張！
- **レベルアップ**: 売上とEXPで「評判のトラットリア」「大人気のロードサイド店」「伝説のサイゼリーゼ本店」へランクアップ！

### 4. 操作性 & スマホ横画面対応
- **スマホ横画面（ランドスケープ）最適化**: 端末を横向きにすることで大画面で直感的に遊べます。
- **レトロ音響**: Web Audio APIによる注文ベル「チーン！」、コイン音「チャリン！」、調理ジュージュー音、レベルアップファンファーレ、陽気なイタリアン8bitタランテラBGM搭載（ミュート/ON/OFF可能）。

## 🚀 起動方法

```bash
# 依存パッケージのインストール (初回のみ)
npm install

# 開発サーバー起動
npm run dev

# またはビルドしてプレビュー
npm run build
npm run preview
```

ブラウザで `http://localhost:3000` または `http://localhost:4173` にアクセスしてお楽しみください。
